# ARIA: AI Requirements Assistant

Build a modern responsive SaaS web application called ARIA (AI Requirements Intelligence Assistant).

The application helps sales representatives, pre-sales consultants and client-facing teams conduct AI-guided requirement gathering sessions and automatically generate developer-ready technical documentation.

Style:
• Enterprise SaaS inspired by Linear, Notion, Stripe and Vercel
• White background
• Blue and teal accents
• Soft gray cards
• Rounded corners
• Minimal shadows

Pages:
• Authentication (Login, Google Sign-In, Forgot Password)
• Dashboard (Recent Projects, New Session, Session Status, Search)
• New Session (Client Name, Project Name, Industry, Raw Client Brief, Upload, Start Guided Intake)
• Guided Conversation (Chat interface with requirement outline sidebar showing Business Goals, Users, Features, Workflows, Business Rules, Integrations, Reports, Non-functional Requirements and completion progress)
• Generated Documents (BRD, SRS, User Stories, Acceptance Criteria, Client Summary with Copy, Download and Regenerate)
• Approval Screen (Inline editing, ambiguity flags, Approve, Request Changes)
• Client Summary (Printable plain English summary)
• Export Screen

Use React, Tailwind, reusable components, responsive layouts, loading states and markdown rendering.
